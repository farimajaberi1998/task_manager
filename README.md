# Task Manager API

A robust RESTful API for managing tasks, built as part of a professional backend development roadmap. This project demonstrates clean code practices, CRUD operations, and structured API design using Python and Django.

## 🚀 Features
- **Full CRUD Operations**: Create, Read, Update, and Delete tasks.
- **RESTful Architecture**: Follows industry standards for API design.
- **Scalable Structure**: Built with a modular approach for future frontend integration.

## 🛠 Tech Stack
- **Backend**: Python 3.x, Django 4.x
- **API Framework**: Django REST Framework (DRF)
- **Database**: SQLite (Development) / PostgreSQL (Planned)
- **Version Control**: Git & GitHub
